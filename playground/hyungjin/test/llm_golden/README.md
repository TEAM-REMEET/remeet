# TS3003 새 Golden Set

입력 전사문 전체를 읽고 `../input/criteria.md`의 안건 단위 경계 기준으로 새로 판정했다. 기존 AMI 주제 라벨이나 기존 Golden Set은 정답으로 사용하지 않았다. `../meetings/`의 한국어 발화는 입력 텍스트와의 일치 및 발화 번호 연결에만 사용한다.

## 읽는 방법

- `boundary_positions`: 확정한 경계의 위치. 예를 들어 80은 [79]와 [80] 사이이며 [80]이 새 구간의 첫 발화다. 회의 시작 [1]은 경계 수에 포함하지 않는다.
- `segments`: 채택 경계로 나눈 전체 발화의 연속 범위, 논의 대상, 결과 요약.
- `candidates`: 검토한 경계 후보의 앞·뒤 대상, 세 질문, 제외 유형, 판정, 발화 인용 근거, 재검토 확인.
- 모든 발화 번호는 입력 파일의 앞부분 메타데이터 3행과 빈 줄을 제외하고 1부터 센다. `../meetings/회의ID.json`의 `utterances` 배열 순서와 일치하며 [1]은 `u0001`이다.
- 후보는 의미 있는 전환과 혼동하기 쉬운 지점들을 선정한 목록이다. 나열하지 않은 인접 발화 위치도 경계가 아니다.
- `new_agenda`만 참/O이며 제외 기준은 질문의 참 여부보다 우선한다. 짧은 맞장구만으로 경계를 만들지 않는다.
- 명시적이고 대상이 분명한 전환 안내는 새 구간에 포함한다. 대상이 아직 없는 진행 예고는 그 위치에서 경계로 잡지 않는다.
- 하나의 조사·설계 보고 내 결과와 권고는 보고의 세부 측면으로 묶고, 서로 다른 담당 영역의 보고 전환은 별도 대상으로 본다. 발표 뒤 동일 제안의 질의응답은 나누지 않는다.
- 기존 선택지 보고에서 특정 부품을 실제로 선택하는 집중 논의로 전환한 곳은 대상의 범위를 확인해 판정했다. 단순히 발표가 토론으로 바뀌었다는 이유만으로 나누지는 않는다.
- 같은 결정으로 돌아오는 재논의는 경계가 아니다. 따라서 연속 구간 안에 다른 안건의 재등장이 포함될 수 있다. 구간 제목만으로 모든 발화의 의미 라벨을 대체하면 안 된다.

## 주요 재검토 사항

- TS3003a: 동물·그림 그리는 사람이 바뀌어도 같은 도구 연습이다. 노트북 문제는 삽입 화제이며, 통합 조작·내구성·배터리 표시는 서로 다른 요구 대상이다.
- TS3003b: 문자 방송 유지와 목표 연령 재검토는 기존 결정의 재논의다. 거치대의 찾기 신호는 거치대 기능의 구체화로 묶었다.
- TS3003c: 음성 인식, LCD, 전원, 칩, 케이스, 조작 배치는 별도의 결정 대상이다. 음성 인식 제외 후 전원으로 돌아오는 [324]와 케이스를 다시 고르는 [560]은 재논의로 제외했다.
- TS3003d: 원가 조정 중 버튼·LCD·케이스 대안을 바꾸는 것은 같은 예산 충족 안건이다. [584]의 프로젝트 평가 전환은 실행되지 않았고 [593]부터 빠뜨린 제품 평가를 한다. 실제 프로젝트 회고는 [776]부터다.
- TS3003d의 41/49점·84%는 회의에서 보고한 수치다. 개별 점수가 모두 명시적으로 합의된 것으로 보충하지 않았다. 예산 충족 주장에는 거치대 비용 누락이라는 제한이 있으며, 목표 고객 변경도 제안 수준이다.

## 검증

2026-10-26 실행 결과: 4개 회의 모두 통과. 전체 2,949개 발화의 입력 일치, 85개 후보의 판정 일관성, 36개 경계와 40개 구간의 연결·전체 범위를 확인했다.

`validate.ps1`은 네 입력과 한국어 발화의 일치, 번호·인용 범위, 판정 규칙, 후보·경계 연결, 구간의 누락·중복 여부를 검사한다.

```powershell
pwsh -NoProfile -File ./validate.ps1
```

의미 판정은 동일 분석자가 기준과 전체 문맥을 다시 대조했다. 자동 검사는 의미의 정답 여부를 증명하지 않으며 독립된 인간 검수나 다중 평가자 합의는 아직 없다.
