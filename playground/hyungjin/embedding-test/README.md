# 회의 주제 나누기 — 로컬 웹

기존 01~03 노트북의 함수를 `pipeline.py`로 분리하고 Streamlit 화면을 연결했다. 노트북과 기존 결과는 그대로 둔다.

## 실행

`remeet` 폴더에서 실행한다. 저장소의 기존 Python 환경을 사용한다.

```powershell
uv sync
uv run streamlit run playground/hyungjin/embedding-test/app.py --server.address 127.0.0.1 --server.headless true --browser.gatherUsageStats false
```

브라우저에서 http://127.0.0.1:8501 을 연다. 종료는 실행한 터미널에서 Ctrl+C.

API 키는 저장소 `.env` 또는 환경변수에 둔다. 화면에 입력하지 않는다.

```dotenv
OPENAI_API_KEY=...
GEMINI_API_KEY=...
```

Gemini는 `GOOGLE_API_KEY`도 지원한다. Hugging Face 모델은 최초 실행에 다운로드·메모리가 필요하다. API 모델을 실행하면 해당 제공자에게 텍스트가 전송된다.

## 사용

1. 기존 회의 20개 중 선택하거나 UTF-8 TXT, 기본 DOCX 또는 텍스트를 입력한다. DOCX의 표·이미지·텍스트 상자는 지원하지 않으며, 내용 누락을 피하려고 입력을 거부한다.
2. 저장할 회의 이름과 임베딩 모델을 정한다. 윈도우·오버랩은 **문자 수**이며, 짧은 발화도 삭제하지 않는다. Gemini 임베딩은 현재 `gemini-embedding-001` 전용이며 윈도우당 1,800 UTF-8 바이트로 제한한다.
3. 후보 선택 방법을 고른다. `depth`는 양쪽 주변 최대 유사도에서 현재 유사도가 얼마나 낮아졌는지 합한 값으로, 확률이 아니다. 최소 거리는 후보 사이와 본문 양 끝에도 적용한다.
4. 후보만 탐색하거나 LLM 검토까지 실행한다. OpenAI SDK의 `base_url`을 바꿔 OpenAI/Gemini를 연결한다. 시스템 프롬프트는 별도 펼침 영역에서 수정한다. 좌우 문맥은 각각 최대 400자다.
5. 후보 문맥·판단 이유·원문 인용과 주제별 **전문**을 읽고 JSON을 내려받는다. 그래프의 붉은 선은 후보 위치다. 경계 위치를 자동 이동하거나 전문을 요약하지 않는다.

위쪽의 **저장한 결과 열기**에서 기존 노트북 실행과 웹 실행 결과를 읽을 수 있다. 화면 열람·후보 선택·다운로드는 모델을 호출하지 않는다. 실행 버튼을 누를 때만 분석한다.

## 저장과 재사용

실행마다 `outputs/<회의이름_임베딩모델_LLM모델>/<실행시각-식별자>/`에 저장한다. 후보 탐색만 실행하면 LLM 이름을 생략한다. 파일명에 쓸 수 없는 문자는 `-`로 바꾸고 원래 모델 ID는 메타데이터에 남긴다. 같은 회의를 다시 실행해도 이전 결과를 덮어쓰지 않는다.

- `<회의이름_임베딩모델_LLM모델>.json`: 설정·메타데이터·원문·점수·후보·검토·주제 전문·사용량·출처.
- `<회의이름_임베딩모델_LLM모델>_topics.json`: 읽기 쉬운 주제별 전문.
- `source.txt`, `blocks.json`, `windows.json`, 후보 JSON, 요청·원본 응답·검토 로그.
- `outputs/cache/`: 임베딩 벡터와 검증된 응답. 모델·원문·윈도우가 같은 임베딩을 재사용하고, 후보 선택 방법만 바꿀 때 다시 임베딩하지 않는다. LLM 응답은 원문·요청 문맥·프롬프트·모델·주소·응답 형식이 같을 때만 재사용한다.

보류·일부 실행·API 실패·후보 없음은 완성된 주제 분할로 표시하지 않는다. 검토 후보 수 제한은 일부 실행 테스트용이다. 완성 시 구간들을 이어 붙여 분석 범위 원문과 정확히 같은지 검사한다. 머리말과 앞뒤 공백은 원문에 보존하며, 주제 분할 범위는 본문 시작·끝 좌표로 별도 표시한다.

화면의 Stop 또는 터미널 종료로 중단한 실행은 완료 파일이 없을 수 있다. 이미 저장된 검증 응답은 다음 같은 설정 실행에서 재사용한다. 진행 중 API 요청의 과금 취소는 보장하지 않는다. 실패한 응답을 성공으로 재사용하지 않는다.

## 검증

```powershell
uv run python -m unittest discover -s playground/hyungjin/embedding-test -p test_pipeline.py -v
```

문자 윈도우·400자 제한·입력·인용 검사·원문 복원·오류·캐시·파일명·화면 조작 시 호출 방지를 테스트한다. 테스트의 모델 호출은 대체 응답을 사용한다. 기존 ES2004a 임베딩과 LLM 응답 4건을 재사용한 실행도 확인했으며 추가 API 호출 없이 3개 주제 전문을 저장했다. 이는 경계 정확도 평가가 아니다. 실제 Gemini 호출과 여러 모델의 성능·비용 비교는 별도 실험이다. 사용량은 제공자 응답을 저장하며 요금을 추정하지 않는다.
