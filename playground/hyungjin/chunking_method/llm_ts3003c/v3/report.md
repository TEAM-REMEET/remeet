# TS3003c 경계 후보 LLM 검증 실험 결과

BAAI/bge-m3 · 문장 보존 목표 윈도우 200자 / 오버랩 100자 · depth≥0.10 후보 39개. 동일 프롬프트와 gpt-6-luna(low)로 미병합, 최대 900자, 최대 1,200자 청크를 비교했다. 입력은 시스템 프롬프트, 발화 번호를 붙인 청크 원문, 예상 경계(후보 문자 위치에서 가장 가까운 발화 시작점)와 ±5발화 탐색 범위이며, LLM은 후보마다 O/X를 판정하고 O이면 탐색 범위 안에서 실제 경계 발화를 골랐다. 정답은 API에 보내지 않고 로컬 평가에만 사용했다.

## 경계 정확도

주 지표는 정확한 발화 일치 기준 일대일 대응이고 ±3발화는 보조 지표다. 탐색 범위 안에 정답이 있는 것은 9/11개다(재현율 상한).

근거 인용은 `[번호]`, `[uNNNN]`과 함께 범위 표기 `[81-89]`도 인정했다(범위는 양 끝 번호가 청크 안에 있어야 한다). v3에서는 v2 실행 후 정한 이 규칙을 호출 전부터 적용했다. 응답 원문은 수정하지 않았다.

처리 실패 요청: baseline/R0021, merge_1200/R0001. 해당 요청의 후보는 판정 없이 남았으므로 부분 완료 조건의 지표는 완료 조건과 직접 비교할 수 없다. 실패 내용은 `calls/*.state.json`과 `usage.json`의 `failed_requests`에 있다.

## 사용량

호출 81회, 재시도 0회, 입력 125,189 토큰, 출력 40,873 토큰, 추론 17,673 토큰, 누적 지연 732.29초. 단가 기반 추정 비용은 $0.032955 USD이며 실제 청구서가 아니다.

## 파일

- `results/<조건>/TS3003c.json`: `test/llm_golden/TS3003c.json`과 같은 최상위 키·`segments`·`candidates` 구조이며 골든 검증 규칙을 통과했다. 윈도우·오버랩은 `annotation_scope`와 `evaluation.json`에 기록했다.
- `results/<조건>/candidate_judgments.json`: 요청별 후보 39개 판정 원본, `calls/`: API 요청·원응답·사용량을 포함한 원자료.
- `system_prompt.txt`, `manifest.json`: 시스템 프롬프트 원문과 입력·설정 해시.

## 제한

단일 회의의 단회 탐색 실험이며 전체 회의에 대한 일반화 성능을 확정하지 않는다. LLM은 예상 경계 ±5발화 안에서만 위치를 보정한다. 이전 실행 결과는 `../v1_boundary_options/`, `../v2/`에 보존했다.
