# 200·300자 윈도우의 중복 후보 분석

기존 임베딩·후보 결과를 재사용했다. 새 모델 실행은 하지 않았다. 중복은 같은 회의·조건에서 서로 다른 후보 중심이 같은 정답 경계의 평가 반경 안에 2개 이상 들어온 경우로 정의했다. 후보 위치 자체는 기존 로직에서 중복 제거된 값이다.

아래 값은 20개 회의 전체 실행이 완료된 BGE-m3와 Jina의 조건별 결과를 모은 것이다. 윈도우 크기·모델마다 18개 설정(오버랩 3개 × 후보 방식 2개 × 임계값 3개), 총 2,754개의 정답-설정 조합을 평가했다. 괄호는 해당 반경에서 하나 이상 후보가 포함한 정답 중 복수 후보가 포함한 비율이다.

| 모델 | 윈도우 | 평가 반경 | 복수 후보 포함 정답 / 포함 정답 | 비율 |
|---|---:|---:|---:|---:|
| BGE-m3 | 200자 | ±200자 | 707 / 1,751 | 40.4% |
| BGE-m3 | 200자 | ±300자 | 1,169 / 1,942 | 60.2% |
| Jina text-matching | 200자 | ±200자 | 703 / 1,773 | 39.7% |
| Jina text-matching | 200자 | ±300자 | 1,181 / 1,946 | 60.7% |
| BGE-m3 | 300자 | ±200자 | 74 / 1,365 | 5.4% |
| BGE-m3 | 300자 | ±300자 | 315 / 1,574 | 20.0% |
| Jina text-matching | 300자 | ±200자 | 81 / 1,360 | 6.0% |
| Jina text-matching | 300자 | ±300자 | 289 / 1,572 | 18.4% |

200자 윈도우에서는 후보가 더 촘촘해 동일 경계가 여러 후보 문맥에 포함되는 경우가 많았다. 평가 반경을 ±200자에서 ±300자로 넓히면 중복 비율이 더 올라갔다. 300자 윈도우에서는 중복 비율이 낮았다.

권고 설정에서도 중복 포함이 나타난다. ±200자 최고 조건인 BGE-m3 200/150자·depth 0.10에서는 153개 경계 중 129개(84.3%)가 복수 후보에 포함됐다(최대 4개 후보, 추가 포함 205회). ±300자 최고 조건인 Jina 200/100자·depth 0.10에서는 110개(71.9%)가 복수 포함됐다(최대 3개 후보, 추가 포함 143회).

MPNet과 Alpha STS의 부분 실행도 CSV에 포함했지만, 완전 실행 설정이 없어 위 모델 비교에는 넣지 않았다.

## 선별 방식·임계값별 후보 결과

아래는 각 `method × threshold`를 따로 집계한 값이다. 각 셀은 `BGE-m3 복수/포함 비율; Jina 복수/포함 비율`이며, 각 모델의 세 오버랩 설정에서 **실제로 선출된 후보 위치**를 사용했다. 선택된 후보 수는 상세 CSV에 있다.

| 선별 값 | 200자 창 ±200자 | 200자 창 ±300자 | 300자 창 ±200자 | 300자 창 ±300자 |
|---|---|---|---|---|
| depth 0.02 | BGE 222/437 (51%); Jina 215/438 (49%) | BGE 347/457 (76%); Jina 346/456 (76%) | BGE 20/361 (6%); Jina 26/361 (7%) | BGE 96/416 (23%); Jina 96/416 (23%) |
| depth 0.05 | BGE 219/435 (50%); Jina 213/438 (49%) | BGE 344/457 (75%); Jina 341/456 (75%) | BGE 19/357 (5%); Jina 25/356 (7%) | BGE 93/412 (23%); Jina 90/412 (22%) |
| depth 0.10 | BGE 202/428 (47%); Jina 190/428 (44%) | BGE 327/455 (72%); Jina 315/449 (70%) | BGE 15/341 (4%); Jina 18/335 (5%) | BGE 76/398 (19%); Jina 72/390 (18%) |
| quantile 0.02 | BGE 4/66 (6%); Jina 7/80 (9%) | BGE 13/95 (14%); Jina 15/106 (14%) | BGE 0/47 (0%); Jina 0/45 (0%) | BGE 3/52 (6%); Jina 0/51 (0%) |
| quantile 0.05 | BGE 14/142 (10%); Jina 24/147 (16%) | BGE 36/191 (19%); Jina 49/193 (25%) | BGE 5/99 (5%); Jina 2/99 (2%) | BGE 12/112 (11%); Jina 6/112 (5%) |
| quantile 0.10 | BGE 46/243 (19%); Jina 54/242 (22%) | BGE 102/287 (36%); Jina 115/286 (40%) | BGE 15/160 (9%); Jina 10/164 (6%) | BGE 35/184 (19%); Jina 25/191 (13%) |

200자 창의 depth 선출은 복수 포함 비율이 높다. quantile은 선택 후보가 적어 중복 비율이 낮다. ±300자 평가에서는 어느 설정이든 ±200자보다 같은 정답을 복수 후보가 포함할 가능성이 커진다.

- 정답·후보 좌표별 상세: `duplicate_boundary_cases.csv`
- 선별 임계값별 집계(오버랩별 후보 수 포함): `duplicate_boundary_by_selection.csv`
