# 겹치는 후보 구간 병합 분석

기존에 저장된 후보 좌표와 정답을 재사용했으며 임베딩이나 후보 선출을 다시 실행하지 않았다. 각 선출 후보 중심 p에 평가 반경 r을 적용해 본문 안의 [p-r, p+r] 문맥 구간을 만들고, 겹치거나 맞닿는 구간을 하나로 병합했다. 글자 길이는 병합 구간의 끝 좌표−시작 좌표로 계산했다. 정답 포함은 기존처럼 |정답−후보 중심|≤r로 판정했다.

각 표 행은 모델·윈도우 크기·오버랩 크기·선출 방법·임계값·평가 반경의 조합 하나다. 병합 구간은 기존 후보 구간의 합집합이므로 포함률이 바뀌지 않아야 하며, 288개 조합 모두 기존 집계의 포함 정답 수와 일치하는 것을 확인했다.

기존 오탐률은 선택 후보 중심 단위, 병합 오탐률은 병합된 구간 단위다. 최근접 후보 거리는 기존 후보 중심에서 계산해 기존 지표 정의를 유지했다. 부분 실행 모델은 처리한 회의 수를 함께 표시한다.
