# BGE 경계 후보 병합 및 정답 거리 실험 보고서

작성일: 2026-10-29

## 목적과 결론

기존 BGE-m3 임베딩 결과를 재사용하여, 임계값과 병합 조건에 따라 회의별 경계 그룹 수와 정답 경계까지의 거리를 비교했다. 임베딩 재계산과 LLM 호출은 수행하지 않았다. O/X 허용 범위를 정하지 않았으므로 정답 누락률이나 정확도는 산출하지 않았다.

**결론:** 18개 조합 모두에서 20개 회의 전체가 경계 그룹 15개 이하를 만족하지 못했다. 그룹 수가 가장 적은 조건은 K=0.2·gap=400·span=800으로 총 300개이나, 정답별 최근접 거리 평균은 229.6자·14.2발화다. 거리 평균이 가장 작은 K=0.0·gap=200은 109.7자·7.4발화지만 그룹이 626개로 회의당 평균 31.3개다. 현재는 호출량과 거리 사이의 절충을 확인한 단계이며, 품질 기준 없이 최종 설정을 확정하지 않는다.

## 데이터와 계산 방법

- 입력: 20개 회의, LLM 참조 정답 총 153개. 정답은 독립 인간 검수나 다중 평가자 합의를 거치지 않았다.
- 기존 설정: BAAI/bge-m3, 윈도우 목표 200자, 오버랩 목표 100자, 문장 보존. 각 윈도우 전체를 임베딩했다.
- 보관된 전체 유사도·depth 데이터 재사용. 입력 파일·정답·정규화 원문의 SHA-256과 정답 좌표를 기존 manifest와 대조했다. 기존 depth ≥ 0.10 후보 목록을 20/20회의에서 다시 만들어 저장된 후보 목록과 일치함을 확인했다.
- depth는 기존 좌우 반경 3의 정의를 그대로 사용한다. 회의별 전체 인접 윈도우 depth의 평균 + K × 모집단 표준편차(ddof=0)를 임계값으로 한다. K는 0.0, 0.2다.
- 이전과 같이 유사도의 국소 최솟값 중 depth가 임계값 이상인 위치를 선출한다. 양끝은 존재하는 이웃보다 작아야 하고, 동률 구간은 양쪽보다 작거나 같으면서 한쪽보다 엄격히 작아야 한다.
- 후보를 문자 위치순으로 놓고 인접 후보 간격 ≤ gap, 첫 후보부터 마지막 후보까지의 범위 ≤ span이면 순차 병합한다. 각 그룹에서 depth가 가장 높은 후보를 대표 위치로 정하고, 동률이면 앞쪽을 택한다. 초기 ±300자 범위는 사용하지 않는다.
- 각 정답은 문자 거리 기준 가장 가까운 대표 위치와 독립적으로 연결한다. 동률이면 앞쪽 대표를 택한다. 발화 거리는 해당 대표 위치에서 가장 가까운 발화 시작 번호와 정답 번호의 차이다. 동률이면 앞쪽 발화를 선택한다.
- 독립 최근접 비교이므로 여러 정답이 같은 대표 경계를 공유할 수 있다. 공유 그룹 수를 별도로 표시하며, 일대일 매칭이나 경계 정답 판정으로 해석하지 않는다. 문자 평균은 전체 153개 정답에 동일한 가중치를 준 값이다.
- 경계 그룹 수 + 1은 대표 문자 위치에서 회의 본문 전체를 나누고 각 구간을 한 번씩 요약한다는 가정의 호출 추정치다. 텍스트 분할·최대 입력 길이·중복·발화 보존·실제 API 호출은 검증하지 않았다. span 상한은 병합 전 후보 좌표 범위이며, 최종 요약 청크 길이 제한이 아니다.

## 주요 조건 비교

- **거리 우선:** K=0.0, gap=200. 626그룹, 회의당 평균 31.3그룹. 15개 이하인 회의는 3/20. 정답 거리 평균 109.7자·7.4발화, 중앙 81자·6발화.
- **그룹 수 우선:** K=0.2, gap=400, span=800. 300그룹, 회의당 평균 15.0그룹. 15개 이하인 회의는 7/20. 정답 거리 평균 229.6자·14.2발화, 중앙 194자·11발화.
- **15개 이하 회의 수 우선:** K=0.0, gap=400, span=800. 305그룹, 15개 이하 10/20회의. 평균 거리는 227.8자·14.3발화. 전체 그룹 수가 가장 적은 조합보다 5그룹 많지만 조건을 만족한 회의가 3개 더 많다.

15개 이하에는 10개 미만인 회의도 포함한다. 목표를 엄격하게 10~15개로 해석하면 세 번째 조합은 6/20회의다. 두 계산을 표에서 따로 제공한다.

## 해석 및 다음 결정

- 병합 범위를 넓히면 일반적으로 그룹 수는 줄지만, 여러 후보 중 대표 하나만 남으므로 정답과의 거리가 커질 수 있다.
- 거리와 그룹 수만으로 액션 추출이나 요약 품질을 판단할 수 없다. 어떤 거리부터 실무상 허용할지 정하면 그때 범위별 누락과 일대일 매칭을 추가 평가할 수 있다.
- 대표 위치를 가장 높은 depth로 정한 결과다. 그룹 중앙이나 다른 대표 선택 규칙을 사용한 결과는 이번 계산에 포함되지 않는다.
- 그룹 수가 적어도 원본 전체를 분할하면 예상 요약 구간은 그룹 수보다 하나 많다. 요약 품질과 실제 호출 시간·토큰은 별도 실험이 필요하다.
