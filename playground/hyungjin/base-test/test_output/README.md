# TS3003 회의록 베이스 테스트 결과

이 폴더는 AMI Meeting Corpus의 시나리오 회의 **TS3003a, TS3003b, TS3003c, TS3003d**를 대상으로 한 회의록 요약 및 액션 아이템 추출 실험 결과입니다.

## 원본과 라이선스

- 원본: [AMI Meeting Corpus](https://groups.inf.ed.ac.uk/ami/corpus/) — AMI 프로젝트
- 라이선스: [Creative Commons Attribution 4.0 International (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/). [AMI 공식 라이선스 안내](https://groups.inf.ed.ac.uk/ami/corpus/license.shtml)를 참고하세요.
- 변경 사항: 원본 회의 자료를 한국어로 번역하고 발화 단위로 분리했으며, 이를 바탕으로 청크별 요약·액션 추출, 안건별 병합·검증 및 회의록 조립 결과를 생성했습니다. 저장소의 원본 메타데이터상 한국어 번역은 사람 검토 전입니다.
- 이 폴더의 모델 출력은 실험 결과이며, 별도 사람 검토나 최종 사실성 검증이 완료되었다는 뜻은 아닙니다.

원본 자료의 기존 저작권·라이선스·면책 고지 등은 해당하는 배포 원본과 함께 확인하고 유지해 주세요. 코드나 이 폴더의 모든 독자적인 자료가 자동으로 동일 라이선스를 갖는다는 뜻은 아닙니다.

## 폴더 구성

`TS3003a_test`부터 `TS3003d_test`까지 회의별 폴더가 있습니다.

- `00_입력.json`: 회의 정보와 발화별 원문 청크
- `01_청크요약/`, `03_액션/`: 청크별 요약과 액션 후보
- `04_병합전검증/`~`07_재검증/`: 안건별 병합 및 모델 검증 결과
- `13_최종조립_입력.json`, `14_최종회의록.json`: 최종 회의록 조립 입력과 구조화 결과
- `15_사람검토자료.json`: 기존 검증에서 남은 지적과 검토 자료
- `최종_회의록.md`: 화면 확인용 회의록
- `실행정보.json`: 모델, 단계별 호출과 사용량 등 실행 기록. 프롬프트 원본은 상위 `base-test` 디렉터리에서 공통 관리합니다.

JSON의 출처 경로는 **저장소 루트 기준 상대 경로**입니다. 경로는 당시 실행 위치와 실행명을 보존한 기록이며, 이후 폴더 이름 변경이나 산출물 제외 때문에 현재 저장소에서 바로 열리지 않을 수 있습니다.
