# TS3003c 베이스 테스트 결과 검토

## 실행 조건

- 입력: TS3003c 전사문과 PR #35에서 생성된 BGE-M3 핵심 구간. 원문 726개 발화와 구간 발화의 내용·순서가 일치함을 확인했다.
- 경계 탐지: PR에 저장된 결과를 재사용했다. K=0.0, gap=400, span=800. 임베딩을 새로 계산하지 않았다.
- 추출 청크: 15개 핵심 구간을 발화 경계를 유지해 최대 약 1,000자로 후분할한 18개. 추출 입력 오버랩 없음.
- 모델: gpt-6-luna, reasoning effort low. 요약·액션은 독립 호출이며 같은 청크와 호출 직전 안건 목록을 사용했다.
- 호출 40회, 총 175,614 토큰. 호출 시간 합계 285.39초. 금액은 계산하지 않았다.

## 결과

- 청크 18개 중 17개에서 안건을 추출했고, 모두 A001 하나로 연결했다. 18번 청크에는 안건이 없다고 반환했다.
- 1차 병합은 A001 아래 7개 주요 논의 쟁점으로 정리했다.
- 독립 액션 추출은 11개 항목을 반환했다. 결과는 병합·중복 제거 또는 사람 검증을 마친 업무 목록이 아니다.
- LLM 내용 검증은 병합 전 결과에서 누락 2건을 지적했다. 한 번 수정한 후 같은 방식의 재검증은 오류 0건을 반환했다. 이는 LLM의 자체 검토 결과이며 오류가 없다는 객관적 증명이 아니다.
- 자동 확인한 추출·액션·수정 결과의 근거 번호 154개 항목에서 존재하지 않는 번호는 발견되지 않았다. 번호 존재 확인은 해당 발화가 내용을 실제로 뒷받침한다는 검증이 아니다.

## 검증 전후 예시

1. **고객층 맥락:** 검증 전에는 나무색·회흑색 두 버전의 제안이 있었지만 고객층 구분이 빠졌다. 수정 후 발화 82~84를 근거로 제안된 고객층 구분을 추가했다. 원문과 의미가 일치하는지는 추가 사람 검토가 필요하다.
2. **후속 논의:** 검증기는 다음 회의 주제와 디자인 참고·협업 관련 설명의 누락을 지적했다. 수정 결과는 발화 690~696의 여러 내용을 `next_meeting_topics` 한 항목에 함께 넣었다. 작업 안내와 다음 회의 안건을 하나로 묶는 것이 팀의 출력 기준에 맞는지는 사람 검토가 필요하다.

## 확인된 한계

- **전체가 하나의 안건:** 17개 청크가 모두 포괄적인 `콘셉트 설계` 안건에 연결됐다. 결과에는 7개의 소주제가 있지만 이들이 팀의 안건 기준상 별도 안건이어야 하는지는 아직 평가하지 않았다. 이후 안건 연결 기준을 점검할 사례다.
- **검증 범위:** 마지막 청크의 발화 710~725는 안건 미식별로 병합·안건별 검증 입력에서 빠졌다. 이 청크에는 그룹 폴더와 회의 재개 관련 발언이 있다. 안건별 검증은 회의 전체 누락 검증이 아니다.
- **수정 후에도 모순 가능성:** 최종 결과의 결정 항목은 LCD 사용을 전제로 고급형 칩을 결정했다고 쓰지만, 공유 항목은 LCD 채택이 확정되지 않았다고 적는다. 재검증은 이를 지적하지 않았다. 원문과 대조해 판단해야 하며, 재검증 0건을 무오류로 해석하면 안 된다.
- **액션 품질:** `확인 가능한지 살펴본다`처럼 대상이 불명확한 항목과 회의 중 수행한 일일 가능성이 있는 항목이 있다. 실제 후속 업무 여부와 담당자·기한은 원문 검토가 필요하다. 액션 에이전트는 호출 당시 기존 안건 목록만 받으므로 신규 안건의 액션은 ID가 비어 있을 수 있다.
- **비교 범위:** 이번 실행은 병합 전후 검증·재수정을 확인했다. 오버랩 유무, 안건 목록 미제공, 단순 취합과 쟁점별 병합의 대조 실험은 실행하지 않았다.
- **완성 범위:** 최종 회의록 조립 및 3~5문장 회의 전체 요약, 별도의 전체 가독성 검사와 사람 정답 비교는 아직 실행하지 않았다. 노트북은 셀 순서 실행 도구로 실행했으며, 노트북 자체에 실행 출력이 저장된 것은 아니다.

- `04_병합전검증/`: 검증 전 안건별 1차 병합 결과

- `06_수정후/`: 재수정 결과

- `실행정보.json`: 호출 단계, 사용량 및 상태
