- [v1](v1/README.md): 기존 베이스 에이전트 실험. 코드, 프롬프트, 입력과 실행 결과를 함께 보관합니다.
- [v2 계획서](v2/계획서.md): 청크별 요약 후 안건 생성과 오버랩 적용을 위한 실험 계획입니다.
- [v2 실행 안내](v2/README.md): 실행 방법과 단계별 산출물 안내입니다.
