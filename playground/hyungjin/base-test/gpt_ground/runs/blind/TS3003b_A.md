# 회의 요약

**회의:** Real Reaction 신제품 TV 리모컨 개발 프로젝트 2차 회의 — 기능 설계  
**일시:** 2004년 10월 11일  
**참석:** 프로젝트 매니저, 산업 디자이너, UI 디자이너, 마케팅 담당자  
**목적:** 사용자 요구와 제품 기능·작동 설계에 합의하고, 다음 단계의 콘셉트 작업 방향을 정함

## 안건별 요약

### 1. 사용자 조사 및 시장 분석

마케팅 담당자가 사용성 조사와 시장 조사 결과를 공유했습니다. 실험 대상은 100명이었습니다.

- 응답자의 **75%**가 현재 리모컨을 못생겼다고 답했고, **80%**는 더 멋진 디자인이라면 돈을 더 쓸 의향이 있다고 답했습니다.
- **50%**는 리모컨 버튼의 약 10%만 사용한다고 답했으며, **50%**는 리모컨을 자주 잃어버린다고 답했습니다.
- 중요도는 채널 선택과 볼륨 조절이 각각 **10점 만점에 10점**, 전원 버튼은 **9점**, 문자 방송은 **6.5점**이었습니다.
- 응답자의 약 **25%**는 리모컨 사용으로 RSI가 생긴다고 생각했고, **34%**는 새 리모컨 조작법을 익히기 어렵다고 답했습니다.
- 시장 조사에서는 16~46세가 시장의 60%, 46~65세가 40%를 차지한다고 설명했습니다. 다만 연령대별 성향과 프로젝트의 목표 시장을 두고 회의 중 의견 차이가 있었습니다.

**시사점:** 사용하기 쉽고 보기 좋은 디자인, 자주 쓰는 기능의 편리한 조작, 손에 부담을 덜 주는 설계를 고려해야 합니다. 리모컨 분실 방지 기능과 설명용 화면도 제안됐습니다.

### 2. UI 및 작동 설계 발표

- UI 디자이너는 전원·음량 등 공통 기능은 물리 버튼으로 두고, 기기별 기능은 터치스크린에 표시하는 방식의 통합 리모컨을 제안했습니다.
- 버튼은 다양한 연령대가 쓰기 쉽도록 크고 단순하게 하자는 의견이 나왔습니다.
- 터치스크린은 기능을 통합할 수 있지만, 비용과 내구성, 흠집·파손 위험이 우려됐습니다.
- 작동 설계 발표에서는 버튼 입력을 칩이 처리하고 적외선 LED를 통해 TV에 신호를 보내는 일반적인 구조를 설명했습니다.
- 내부 구조와 소재는 단순한 플라스틱 중심으로 구성해 비용을 관리하고, 소재 고급화보다는 디자인과 UI에 투자하자는 제안이 있었습니다.

**정리:** 터치스크린 채택은 확정되지 않았습니다. 비용과 내구성을 검토할 필요가 있습니다.

### 3. 제품 범위와 목표 고객

프로젝트 매니저가 다음 요구사항을 제시했습니다.

- 제품은 **TV 전용 리모컨**으로 개발합니다. 여러 기기를 통합하거나 인터넷 기능을 포함하면 복잡성과 개발 기간이 늘어날 수 있다는 판단입니다.
- 별도의 신제품이 젊은 층을 겨냥할 예정이므로, 이번 제품은 **40세 이상 고객**을 대상으로 하자는 방향을 제안했습니다.
- 회의에서는 노인층 특화 제품의 가능성도 논의됐고, 구체적인 대상 연령으로 **60~80세**가 거론됐습니다. 다만 최종 연령 범위는 확정되지 않았습니다.
- 회사 이미지를 제품의 디자인과 작동 방식에 반영하자는 요구가 있었습니다.

마케팅 담당자는 문자 방송의 사용 가치와 기존 조사 결과를 근거로 이를 제외하는 데 반대했습니다. 특히 자막 기능이 청각 장애인과 고령 사용자에게 유용하다는 의견이 나왔습니다.

**결정:** 문자 방송 기능은 유지하는 방향으로 의견을 모았습니다. 문자 방송 버튼을 자막 기능과 연계해 장점으로 만들자는 아이디어도 나왔습니다.

### 4. 조작 버튼과 부가 기능

- 버튼 수를 줄이고 조작을 단순하게 하자는 제안이 있었지만, TV 전용 리모컨 자체에 필요한 기능이 제한적이므로 버튼 수를 줄이는 것만으로 경쟁 우위를 만들기는 어렵다는 의견도 나왔습니다.
- 숫자 버튼을 유지할지, 스크롤 버튼이나 조이스틱으로 대체할지는 논의됐지만 **결론이 나지 않았습니다**. 채널을 빠르게 직접 선택하는 기능과 고령 사용자의 익숙함이 주요 고려사항입니다.
- 리모컨을 찾기 쉽도록 버튼을 누르면 소리가 나는 **분실 방지 기능**이 제안됐습니다.
- **거치대**도 제안됐으며, 거치대에 리모컨 찾기 버튼을 두거나 충전 기능을 넣는 방안이 논의됐습니다.
- 버튼 기능을 알려주는 **간단한 LCD 화면**이 제안됐습니다. 터치스크린이 아닌 기본 화면으로 버튼 설명이나 피드백을 제공하는 아이디어이며, 비용과 필요성은 추가 검토가 필요합니다.
- 거치대와 LCD를 모두 적용할지, 어느 기능을 우선할지는 결정되지 않았습니다.

## 주요 합의 및 미결 사항

### 합의된 방향
- TV 전용 제품으로 개발한다.
- 단순하고 쉽게 익힐 수 있는 조작을 지향한다.
- 문자 방송 기능은 유지하는 방향으로 진행한다.
- 고급 소재보다 기본 소재를 사용해 비용을 관리하고, 디자인과 사용성에 집중한다.
- 고령 사용자 친화성을 주요 설계 고려사항으로 삼는다.

### 추가 검토가 필요한 사항
- 목표 연령 범위: 40세 이상인지, 60~80세 중심인지
- 숫자 버튼을 포함한 버튼 구성 및 배치
- 터치스크린 또는 단순 LCD 화면 채택 여부
- 거치대, 분실 방지 소리, 충전 기능의 구현 여부와 우선순위
- 기능 추가에 따른 비용 및 내구성 영향
