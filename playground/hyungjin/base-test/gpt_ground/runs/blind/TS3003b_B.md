# Real Reaction 신제품 TV 리모컨 개발 프로젝트 — 2차 회의록

- **일시:** 2004년 10월 11일 / 약 37분
- **참석:** 프로젝트 매니저(PM), 산업 디자이너, UI 디자이너, 마케팅 담당자
- **목적:** 사용자 요구사항, 기술적 기능, 작동 방식에 대한 방향을 합의하고 다음 설계 단계의 과제를 정함

## 1. 핵심 결과

- **TV 전용 리모컨**으로 개발 범위를 제한한다.
- 회사가 제시한 **40세 이상 타깃**을 바탕으로, 회의에서는 **60~80세 고령층 중심 제품**으로 구체화하는 방향을 논의했다. 세부 타깃은 추가 조사가 필요하다.
- 당초 제외 요구가 있었던 **문자 방송은 유지하기로 합의**했다. 자막 접근성과 사용자 수요가 주요 근거였다.
- 조작은 **익숙하고 단순하게**, 버튼은 **크고 명확하게 배치**하는 방향을 지향한다.
- **거치대·분실 알림·소형 LCD**를 차별화 후보로 검토한다. 비용과 구현 가능성은 미확정이다.
- 다음 단계에서 **부품 콘셉트와 UI 콘셉트**를 구체화한다.

## 2. 안건별 요약

### 안건 1. 사용자 조사 및 시장 분석

**공유 내용**
- 마케팅 담당자가 사용자 **100명**을 대상으로 관찰·설문을 진행했다.
- 주요 결과:

| 항목 | 조사 결과 |
|---|---|
| 기존 리모컨의 외관 | 75%가 자신의 리모컨이 못생겼다고 응답 |
| 디자인에 대한 지불 의향 | 80%가 보기 좋은 리모컨에 추가 지출 의향 |
| 버튼 활용도 | 50%가 전체 버튼의 약 10%만 사용 |
| 분실 경험 | 50%가 방 안에서 리모컨을 자주 잃어버림 |
| 학습 어려움 | 34%가 새 리모컨 조작법을 익히기 어렵다고 응답 |
| 신체 부담 | 약 25%가 리모컨 때문에 RSI가 생긴다고 인식 |
| 기능 중요도 | 채널·볼륨 10점, 전원 9점, 문자 방송 6.5점 |

※ RSI 관련 수치는 응답자의 인식이며, 의학적 인과관계를 확인한 결과는 아니다.

**시사점**
- 자주 사용하는 기능을 쉽게 찾고 조작할 수 있어야 한다.
- 채널·볼륨 버튼은 사용 빈도를 고려해 내구성을 확보해야 한다.
- 버튼 수 축소, 학습 용이성, 분실 방지 기능에 기회가 있다.
- 초기 마케팅 제안은 젊은 층 중심이었으나, 이후 제시된 회사 요구에 따라 타깃 방향을 조정했다.

### 안건 2. 사용자 인터페이스 설계

**초기 제안**
- 전원·볼륨 등 공통 기능은 물리 버튼으로 유지한다.
- 여러 기기의 개별 기능은 터치스크린에 표시한다.
- 물리 버튼은 크고 단순하게 구성한다.

**논의 결과**
- TV 전용으로 범위가 좁혀지면서 **다기기 전환형 터치스크린의 필요성은 낮아졌다.**
- 터치스크린은 비용, 파손 및 흠집 위험이 제기되어 채택되지 않았다.
- 숫자 버튼을 스크롤·조이스틱으로 대체하는 방안도 논의했으나, 고령층의 익숙함과 채널 직접 입력을 고려해 **기존 숫자 입력 방식을 유지하는 쪽으로 의견이 모였다.**
- 버튼을 극단적으로 줄이기보다는 **배치·가독성·사용 편의성**을 확보하는 것이 중요하다는 의견이 나왔다.

**후속 검토**
- 버튼을 눌렀을 때 기능 설명을 보여주는 **소형 일반 LCD**를 검토한다.
- 이는 초기 터치스크린 제안과는 별개이며, 비용 검증이 필요하다.

### 안건 3. 작동 방식 및 소재

**공유 내용**
- 버튼 입력 → 회로·칩 처리 → 적외선 LED 송신 방식의 기본 구조를 설명했다.
- 단순한 내부 구조와 기본 플라스틱 소재를 제안했다.

**설계 방향**
- 고가 소재보다 **디자인과 UI에 투자**한다.
- 구조를 단순화해 내구성과 생산비를 관리한다.
- 기본 플라스틱 사용에는 긍정적 의견이 있었으나, 구체 소재·부품 사양은 확정되지 않았다.

### 안건 4. 신규 요구사항 및 타깃 고객

**PM이 전달한 요구사항**
1. TV 전용 제품으로 제한
2. 문자 방송 제외
3. 40세 이상 고객 타깃
4. 외관과 작동 방식에 회사 이미지 반영

**논의 및 조정**
- TV 전용 범위는 유지했다.
- 문자 방송 제외에는 반대 의견이 나왔다.
  - 사용자 조사상 중요도가 있음
  - 고령층의 사용 습관과 관련됨
  - 청각 장애인의 자막 접근성에 필요함
- **최종적으로 문자 방송을 유지하기로 합의했다.**
- 자막에 바로 접근하는 큰 버튼도 아이디어로 제안됐다.
- 타깃은 60~80세 중심으로 좁히는 방향이 논의됐지만, 추가 조사가 필요하다.

### 안건 5. 차별화 기능 및 현지화

| 후보 | 논의 내용 | 상태 |
|---|---|---|
| 거치대 | 보관 편의성과 외관 차별화에 활용 | 유력 후보, 비용 검토 필요 |
| 분실 알림 | 거치대 버튼 등을 누르면 리모컨에서 소리 발생 | 긍정적 검토 |
| 충전 기능 | 거치대에 꽂아 충전하는 방식 | 초기 제안, 채택 여부 미정 |
| 소형 LCD | 버튼 기능 설명과 피드백 제공 | 긍정적 검토, 비용 미정 |
| 자막 전용 버튼 | 고령층·청각 장애인 접근성 개선 | 아이디어 단계 |
| 현지화 | 언어 전환 버튼보다 시장별 언어 적용 | 선호 방향 |

**주요 제약**
- 거치대와 LCD를 모두 넣으면 비용 부담이 커질 수 있다는 우려가 있었다.
- 회의 중 **12.5유로**가 비용 기준으로 언급됐으나, 해당 금액의 적용 범위와 세부 원가 기준은 명확히 정리되지 않았다.
- 일반 TV 전용 리모컨과 차별화하기 위해 버튼 수 축소 외의 편의 기능을 검토할 필요가 있다.

## 3. 결정사항과 미결사항

### 확정·합의된 사항
- TV 전용 리모컨 개발
- 문자 방송 유지
- 단순하고 익숙한 조작 방식 지향
- 회사 이미지를 제품 디자인과 사용 경험에 반영
- 다음 단계에서 부품·UI 콘셉트 개발

### 추가 검토가 필요한 사항
- 핵심 타깃을 60~80세로 확정할지 여부
- 거치대·분실 알림·충전·LCD의 최종 채택 조합
- 숫자 버튼을 포함한 최종 버튼 구성
- 자막 전용 버튼의 구현 방식
- 부품별 원가 및 전체 예산 충족 여부
- 시장별 언어 적용 방식
