# playground — 개인 실험실 🧪
꿈을펼치세요       
자유롭게 시도해 보는 공간입니다. 코드가 지저분해도, 실패해도, 리뷰 없이 올려도 됩니다.       

## 채워야 할 내용

기존 실험·노트북·선행연구·모델 비교 자료를 필요할 때 정리해 넣는다.

## 구현 원칙

상위 test와 demo-output은 현재 위치에 보존한다. 검증된 로직만 backend로 옮기며 실험 코드를 운영 코드가 참조하지 않게 한다.

## 완료 기준

실험의 입력·모델·설정·결과가 추적되고 실측과 추정을 구분한다.

## 규칙       
1. 내 이름으로 폴더를 만듭니다: playground/eunje/             
2. 내 폴더 안에서만 작업합니다. (다른 사람 폴더는 읽기만)       
3. 노트북은 _template.ipynb를 복사해서 시작하면 편합니다.       
4. 데이터 파일(.json/.jsonl/.csv 등 큰 파일)과 모델 파일은 올리지 않습니다.       
5. 의미 있는 결과가 나오면 → experiments/LOG.md에 한 줄 기록       
6. 코드가 쓸 만하면 → .py로 정리해서 ai/나 ml/로 옮기는 PR(승격)       

## 이런 걸 올리면 좋아요       
- 임베딩 모델 비교 노트북, 검색 결과 눈으로 확인한 노트북       
- 프롬프트 바꿔가며 Base EXAONE 답변 비교한 기록       
- 배운 개념 정리 (.md)
